# 陈怡安模块详解

## 所属包：`chen_yi_an`

包含 **23 个 Java 文件**（13 个 Servlet、4 个 Model、4 个 DAO、2 个工具类）和 **7 个 JSP 页面** + **1 个 Tag 文件**。

---

## 一、用户系统（6 Servlet + 1 Model + 1 DAO）

### 1.1 Model

#### `User.java` — 用户模型
```
属性：id, email, password, role, displayName, avatar, skills, rating, createdAt
构造方法：User() / User(email, password, role, displayName, skills)
```
- role = "employer"(雇主) 或 "freelancer"(自由职业者)
- rating 是平均评分（0.0 ~ 5.0）
- skills 是技能标签列表

#### `UserDao.java` — 用户数据访问
```
findByEmail(email)     → User      登录验证
findById(id)           → User      获取用户
insert(user)           → int       注册新用户，返回 ID
update(user)           → void      更新个人资料
updateRole(id, role)   → void      切换身份
updateRating(id)       → void      重新计算评分 AVG(review.score)
```

### 1.2 Servlet

#### `LoginServlet.java`
```
GET  /login    → 显示登录页 login.jsp
POST /login    → 验证邮箱密码 → setAttribute("user", user) → 跳转 /projects
```
- 密码明文比较（123456）
- 登录成功将 User 对象存入 session

#### `RegisterServlet.java`
```
GET  /register → 显示注册页 register.jsp
POST /register → 创建用户 + 自动登录 → 跳转 /projects
```
- 检查邮箱是否已存在
- 注册成功后自动帮用户创建钱包（WalletDao.getOrCreate）

#### `LogoutServlet.java`
```
GET  /logout → 清除 session → 跳转 /login
```

#### `ProfileServlet.java`
```
GET  /profile    → 自己的个人主页（从 session 取 user）
GET  /profile/1  → 查看用户 1 的个人主页
```
- 显示用户名、角色、技能、评分

#### `EditProfileServlet.java`
```
GET  /editProfile  → 显示编辑页 editProfile.jsp
POST /editProfile  → 更新 displayName, skills, avatar, password
```

#### `SwitchRoleServlet.java`
```
POST /switchRole → 在 employer / freelancer 之间切换
```

### 1.3 JSP 页面

| 页面 | 功能 |
|---|---|
| `login.jsp` | 登录表单，含错误提示 |
| `register.jsp` | 注册表单 + 角色选择 |
| `profile.jsp` | 个人主页展示 + 编辑入口 |
| `editProfile.jsp` | 编辑个人资料表单 |

## 二、聊天弹窗与交付（6 Servlet + 2 Model + 2 DAO + 1 Tag）

**这是陈怡安最核心、工作量最大的模块。**

### 2.1 Model

#### `ProjectMessage.java` — 聊天消息模型
```
属性：id, projectId, senderId, content, createdAt, senderName
```

#### `ProjectMessageDao.java` — 消息数据访问
```
insert(ProjectMessage)           → int  保存消息
findByProjectId(projectId)       → List<ProjectMessage>  加载项目的历史消息
```

#### `Delivery.java` — 交付物模型
```
属性：id, orderId, projectId, userId, title, description,
      fileName, filePath, fileSize, fileType, createdAt, userName
```

#### `DeliveryDao.java` — 交付物数据访问
```
insert(Delivery)           → int           上传交付物
findByProjectId(pid)       → List<Delivery> 项目所有交付物
findByOrderId(oid)         → List<Delivery> 订单所有交付物
findById(id)               → Delivery      单个交付物
```

### 2.2 Servlet

#### `ChatDeliveryApiServlet.java` — 聊天弹窗核心 API（AJAX 接口）
```
GET  /api/chatDelivery?projectId=X
     → 返回项目信息、消息列表、交付物列表（JSON）

POST action=message → 发送消息
POST action=upload  → 上传文件（.pdf/.zip/.docx/.jpg 等）
POST action=complete → 自由职业者标记完成（order → awaiting_confirm）
POST action=confirm  → 雇主确认完成（order → completed）
```
- 上传文件存到 `WEB-INF/uploads/project_{id}/`
- 30 天自动清理旧文件
- 权限校验：仅雇主和中标者

#### `ChatMessageApiServlet.java` — 聊天消息 API（AJAX 接口）
```
GET  /api/chatMessages?projectId=X
     → 返回历史消息列表（JSON）
POST → 发送新消息
```
- 与 ChatDeliveryApiServlet 类似但更轻量

#### `DeliveryChatServlet.java` — 交付与沟通页面
```
GET  /deliveryChat?projectId=X
     → 渲染交付沟通页面（JSP）
```
- 权限检查：hasAccess() 校验雇主/中标者
- 页面包含：消息列表、交付物列表、上传表单
- 文件清理：30 天前的自动删除

#### `DeliveryDownloadServlet.java` — 交付物下载
```
GET  /delivery/download?id=X → 下载文件
```
- 读取文件并输出到 Response

#### `MyChatProjectsServlet.java` — 我的聊天项目列表
```
GET  /api/myChatProjects → 返回当前用户相关的项目列表（JSON）
```
- 用于聊天弹窗下拉选择项目

#### `ProjectMessageServlet.java` — 项目消息页面
```
GET  /projectMessages?projectId=X → 项目消息页面
POST /projectMessages → 发送消息
```

### 2.3 Tag 文件

#### `chatWidget.jsp` — 聊天弹窗组件
所有项目详情页/订单详情页底部的聊天弹窗，嵌入方式：
```jsp
<jsp:include page="/WEB-INF/tags/chatWidget.jsp" />
```
弹窗内集成：消息输入 + 文件上传 + 消息列表 + 交付物列表

### 2.4 JSP 页面

| 页面 | 功能 |
|---|---|
| `deliveryChat.jsp` | 交付与沟通完整页面 |
| `projectMessages.jsp` | 项目消息页面 |

## 三、钱包（2 Servlet + 2 Model + 2 DAO）

### 3.1 Model

#### `Wallet.java` — 钱包模型
```
属性：id, userId, balance, frozen, createdAt, updatedAt
```
- balance：可用余额
- frozen：托管冻结金额

#### `TransactionLog.java` — 交易流水模型
```
属性：id, userId, type, amount, balanceBefore, balanceAfter,
      frozenBefore, frozenAfter, orderId, description, createdAt
type：recharge(充值) / freeze(冻结) / release(释放) / refund(退款) / income(收入)
```

#### `WalletDao.java` — 钱包数据访问
```
getOrCreate(userId)       → Wallet  获取钱包（没有则创建）
recharge(userId, amount)  → boolean 充值
freeze(userId, amount)    → boolean 冻结（担保托管扣款）
release(userId, amount)   → boolean 释放冻结（确认完成）
refund(userId, amount)    → boolean 退款（解冻退回）
income(userId, amount)    → boolean 收入入账
```

#### `TransactionLogDao.java` — 交易流水数据访问
```
insert(TransactionLog)            → void
findByUserId(userId)              → List<TransactionLog>
```

### 3.2 Servlet

#### `WalletServlet.java`
```
GET /wallet → 显示钱包页面 wallet.jsp
```
- 获取钱包余额 + 交易流水列表

#### `RechargeServlet.java`
```
POST /recharge → 充值 → 跳转 /wallet
```
- amount 参数指定充值金额

### 3.3 JSP 页面

| 页面 | 功能 |
|---|---|
| `wallet.jsp` | 钱包概览：可用余额、冻结金额、充值表单、交易流水列表 |
