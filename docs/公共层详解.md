# 公共层详解

## 所属包：`com.freelite` + `com.freelite.filter` + `com.freelite.service` + `com.freelite.util`

包含 **4 个 Java 文件**：1 个 Filter、1 个 Service、2 个 Util。

---

## 一、AuthFilter.java — 登录认证过滤器

**包：** `com.freelite.filter`

### 作用
拦截所有 HTTP 请求，检查用户是否已登录。未登录的请求自动跳转到登录页。

### 工作原理
```java
public class AuthFilter implements Filter
```
- 实现 `javax.servlet.Filter` 接口
- 在 `web.xml` 中配置，对所有 URL 生效
- 白名单路径直接放行，其他路径检查 session 中的 `user` 对象

### 核心逻辑
```
请求到达 → doFilter() 被调用
  ├─ 请求路径在白名单中？          → 放行
  ├─ 请求路径是静态资源(.css/.js)？  → 放行
  ├─ session 中有 user 对象？       → 放行
  └─ 以上都不是                    → 重定向到 /login
```

### 白名单路径
```
/login, /register, /projects, /project/
/api/myChatProjects, /api/chatMessages, /api/chatDelivery
.css, .js, .png, .jpg, .jpeg, .gif, .ico, .svg, .woff, .woff2
```

## 二、AuthUtil.java — 认证辅助工具

**包：** `com.freelite.util`

### 作用
提供认证相关的静态工具方法，简化 Servlet 中的重复代码。

### 方法

#### `getLoginUser(HttpServletRequest req) → User`
从当前请求的 session 中获取已登录的用户对象。
```java
User user = AuthUtil.getLoginUser(req);
if (user == null) { /* 未登录处理 */ }
```

#### `requireLogin(HttpServletRequest req, HttpServletResponse resp) → User`
要求用户已登录，未登录则跳转到登录页并返回 null。
```java
User user = AuthUtil.requireLogin(req, resp);
if (user == null) return; // 已跳转登录页
```

#### `isLoggedIn(HttpServletRequest req) → boolean`
判断当前请求是否已登录。

## 三、DBUtil.java — 数据库连接工具

**包：** `com.freelite.util`

### 作用
统一管理数据库连接，所有 DAO 都通过 DBUtil 获取 Connection。

### 连接参数
| 参数 | 默认值 | 环境变量覆盖 |
|---|---|---|
| 主机 | localhost | DB_HOST |
| 端口 | 3306 | DB_PORT |
| 数据库名 | freelite | DB_NAME |
| 用户名 | root | DB_USER |
| 密码 | *** | DB_PASSWORD |

### 方法

#### `getConnection() → Connection`
获取数据库连接，每次调用返回新连接。
```java
Connection conn = DBUtil.getConnection();
```
- 自动加载 `com.mysql.cj.jdbc.Driver`
- JDBC URL 包含 UTF-8 编码和时区配置

#### `closeConnection(Connection conn) → void`
安全关闭数据库连接（不抛异常）。

#### `closeStatement(Statement stmt) → void`
安全关闭 Statement / PreparedStatement。

### 使用示例（所有 DAO 的标准模式）
```java
String sql = "SELECT * FROM user WHERE email=?";
try (Connection conn = DBUtil.getConnection();
     PreparedStatement ps = conn.prepareStatement(sql)) {
    ps.setString(1, email);
    try (ResultSet rs = ps.executeQuery()) {
        if (rs.next()) return mapUser(rs);
    }
} catch (Exception e) {
    e.printStackTrace();
}
```

## 四、EscrowService.java — 担保交易服务

**包：** `com.freelite.service`

### 作用
实现项目的**担保交易（托管付款）** 核心逻辑。资金由雇主钱包冻结，工作完成确认后释放。

### 担保交易流程
```
雇主中标投标
  ↓
EscrowService.fundEscrow()
  ├─ 从雇主 wallet 扣款（balance - amount, frozen + amount）
  ├─ 记录 transaction_log（freeze）
  └─ 更新 project.escrow_status = 'funded'
  ↓
自由职业者完成工作 → 雇主确认
  ↓
EscrowService.releaseToFreelancer()
  ├─ 从雇主 wallet 解冻（frozen - amount）
  ├─ 给自由职业者 wallet 加款（balance + amount）
  ├─ 记录 transaction_log（release + income）
  └─ 更新 project.escrow_status = 'released'
  ↓
可选的：EscrowService.refundEscrow() — 退款
  ├─ 解冻并退回雇主 wallet
  └─ 更新 project.escrow_status = 'refunded'
```

### 方法

#### `fundEscrow(int projectId, int employerId, double amount) → boolean`
担保托管：冻结雇主钱包余额。
1. 检查项目状态（必须 open）
2. 调用 WalletDao.freeze() 冻结雇主金额
3. 记录 transaction_log（type=freeze）
4. 更新 project.escrow_status = 'funded'，project 状态改为 'in_progress'

#### `releaseToFreelancer(int projectId, int employerId, int freelancerId, double amount) → boolean`
释放资金：确认完成后将托管资金释放给自由职业者。
1. 检查项目 escrow_status = 'funded'
2. 调用 WalletDao.release() 解冻
3. 调用 WalletDao.income() 给自由职业者加款
4. 记录 transaction_log（type=release + type=income）
5. 更新 project.escrow_status = 'released'

#### `refundEscrow(int projectId, int employerId, double amount) → boolean`
退款：取消项目时解冻并退回雇主。
1. 调用 WalletDao.refund() 解冻退回
2. 记录 transaction_log（type=refund）
3. 更新 project.escrow_status = 'refunded'

### 涉及的数据库操作
| 操作 | 表 |
|---|---|
| 冻结雇主余额 | wallet（UPDATE balance, frozen） |
| 解冻雇主 | wallet（UPDATE frozen） |
| 给自由职业者加款 | wallet（UPDATE balance） |
| 记录流水 | transaction_log（INSERT） |
| 更新项目担保状态 | project（UPDATE escrow_status） |

## 五、调用关系图

```
请求到达
  │
  ▼
AuthFilter (检查登录)
  │
  ├─ 未登录 → /login
  │
  ▼
HttpServlet (doGet / doPost)
  │
  ├─ AuthUtil.getLoginUser() (取当前用户)
  │
  ├─ UserDao / ProjectDao / BidDao / OrderDao / ...
  │     │
  │     ▼
  │   DBUtil.getConnection() (获取数据库连接)
  │     │
  │     ▼
  │   PreparedStatement → ResultSet → DAO 返回数据
  │
  ├─ EscrowService (担保交易)
  │     │
  │     ├─ WalletDao.freeze / release / refund / income
  │     ├─ TransactionLogDao.insert
  │     └─ ProjectDao.updateEscrow
  │
  └─ JSP 页面渲染 (请求转发 / 重定向)
```

## 六、web.xml 配置

公共层的 Filter 和 Servlet 在 `freelite/WebContent/WEB-INF/web.xml` 中统一注册。

### Filter 注册
```xml
<filter>
    <filter-name>authFilter</filter-name>
    <filter-class>com.freelite.filter.AuthFilter</filter-class>
</filter>
<filter-mapping>
    <filter-name>authFilter</filter-name>
    <url-pattern>/*</url-pattern>
</filter-mapping>
```

### 编码过滤器
```xml
<filter>
    <filter-name>encodingFilter</filter-name>
    <filter-class>org.apache.catalina.filters.SetCharacterEncodingFilter</filter-class>
    <init-param>
        <param-name>encoding</param-name>
        <param-value>UTF-8</param-value>
    </init-param>
</filter>
```
